# gb-bridge — мост куратор ↔ разработчик

Публичный канал, чтобы владелец не был курьером. После каждого статуса сюда
кладутся четыре файла:

| Файл | Что внутри |
|---|---|
| `status/latest.md` | статус целиком: сделано / мешает / не хватает |
| `e2e/latest.txt` | вывод сквозного прогона: сайт → интервью → публикация → чат |
| `tests/latest.txt` | лог юнит-тестов целиком |
| `traces/latest.md` | свежие трейсы: вопрос, факты, ответ, флаги |

Персональных данных здесь нет: контакты уходят под маской (`•••` + 4 знака).

## Задания куратора

Задание кладётся файлом `CURATOR.md` в проект-папку разработчика. Разработчик
проверяет его в начале каждого захода.

## Чем это порождается

Артефакты собираются в репозитории `gb-agent`:

```bash
npm test        # → tests/latest.txt
npm run e2e     # → e2e/latest.txt и traces/latest.md
```

Прогон поднимает моки сайта, базы и модели и проходит путь целиком, печатая
каждый шаг с репликами агента. Валидатор в прогоне настоящий.
