# Разбор: кейс №7 матрицы (маникюр) — повтор мимо REPEATED_ANSWER

## Что было в трейсе

Два ответа агента подряд, второй — после новой вводной клиента
(«наращивание снимали месяц назад»):

```
агент 1: …Если вас интересует маникюр с покрытием, стоимость составляет
         2 800 ₽. Какой тип покрытия вы предпочитаете?
агент 2: Понимаю, что состояние ваших ногтей… может вызывать беспокойство.
         Мы можем предложить маникюр с покрытием, который поможет укрепить
         и восстановить ногти. Стоимость услуги составляет 2 800 ₽.
         Какой тип покрытия вы предпочитаете?
```

Для человека это повтор: та же услуга, та же цена и **дословно тот же
финальный вопрос** — заданный посетителю, который на него не ответил,
а дал новую информацию.

## Почему порог не сработал — числа

Метрика повторов: пересечение слов длиннее двух букв, делённое на размер
меньшего ответа; порог 0.6.

```
слов в ответе 1: 25 · слов в ответе 2: 28
общих: 12 (услуги, покрытием, ногти, ногтей, маникюр, стоимость,
           составляет, 800, какой, тип, покрытия, предпочитаете)
overlap = 12 / 25 = 0.48  <  0.6  → повтором не считался
```

Порог размыла вежливая обёртка: «понимаю, что состояние ваших ногтей…
может вызывать беспокойство… укрепить и восстановить» — 16 «новых» слов
без нового содержания раздули знаменатель.

## Почему нельзя просто опустить 0.6

Соседние ответы в одной теме легитимно делят словарь. Пример из этого же
диалога: «Обычно процедура занимает около часа. Какой тип покрытия вы
предпочитаете?» — честный возврат к вопросу после встречного вопроса
клиента. Опущенный до ~0.45 общий порог начал бы бить по таким ответам.

## Починка — второй сигнал вместо сдвига порога

Повтором считается также связка: **дословно тот же ход вперёд** (финальное
предложение, нормализованное) **+ тело без нового содержания** (пересечение
тела без слов хвоста с прошлым ответом > 0.3). Пороги измерены на этом же
трейсе:

```
кейс №7:              хвост дословный · тело 8/24 = 0.33 → повтор ✓
возврат после
встречного вопроса:   хвост дословный · тело 0/8  = 0    → не повтор ✓
```

Порог 0.3 лежит между ними с запасом на опасной стороне: ложное
срабатывание стоит одной регенерации, пропущенный повтор — доверия
посетителя.

Второе исправление тем же заходом: в потоковом чате на повтор раньше сразу
уходил фолбэк P5.1 («этого нет в моих данных») — теперь и там по §5.1
сначала одна регенерация, показанный текст заменяется настоящим ответом;
фолбэк — только если и регенерация повторяется.

## Проверка

- Юнит-тесты на дословных репликах трейса: повтор ловится, честный возврат
  к вопросу и обычный следующий ход не трогаются. Всего тестов: 128.
- Живой перегон кейса №7 (`npm run spheres -- --only маникюр`): второй ответ
  заканчивается другим ходом («Когда планируете записаться?»), флагов нет,
  выдуманных цифр нет.
