# Статус · 31.07, вечер · 2.4 — первая итерация по прогону владельца

Владелец прошёл путь сам и прислал три бага качества интервью. Все три
починены, у каждого — сценарий в прогоне.

## Что было и что стало

**1. Чужие примеры под вопросом.** Компании про химреактивы (`researchlabs`)
показывался чип «ЛДСП, эконом-серии, офисная мебель» — из демо-мастерской
«Верстак». Пример был зашит в код вопроса.

Все заготовки удалены — их в коде больше нет ни одной, это закрыто тестом.
Примеры теперь рождаются из прочитанной карточки: после чтения сайта один
вызов модели даёт 2–3 варианта в терминах этого дела. **Цифры в примерах
запрещены** — выдуманная цифра рядом с полем читается как факт о владельце
(«гарантия 3 года» выглядит как его гарантия). Не собрались — примеров нет,
и это допустимый исход: отсутствие подсказки не ломает интервью, чужая
подсказка ломает доверие.

**2. Отказ от поля записывался фактом.** На вопрос об адресе владелец ответил
«не обязательно» — и агент отчитался «записал: не обязательно».

В классификаторе ходов появился класс `skip`. Распознаётся кодом, до вызова
модели: ход короткий и однозначный, платить за него и зависеть от настроения
модели незачем. Поле остаётся пустым, подтверждение честное — «пропустили —
оставлю пробел в карточке», интервью идёт дальше, а не топчется. В трейсе
`TURN_SKIP`.

**3. Вопросы-заготовки при прочитанном сайте.** Система читала 17 разделов и
спрашивала анкетой.

Тем же вызовом модель переписывает оставшиеся вопросы с опорой на
прочитанное. Смысл вопроса менять нельзя — спрашивается ровно то же самое,
меняется только формулировка. Живая модель в прогоне дала:

```
вопрос: Вижу, у вас есть адрес в Москве — показываете его клиентам?
```

**4. Сводка не по-русски.** «Работаем срок поставки 3-4 недели». Причина:
ключ `terms.timing` держит две разные вещи — режим работы («Пн–Сб 10:00–19:00»)
и длительность («срок поставки 3–4 недели»), а приставка «Работаем» годится
только первой. Длительность теперь идёт отдельной фразой.

```
примеры ответа: — (нет, и это допустимо)

  ✓ подтверждение честное — про пробел
  ✓ отказ не выдаётся за записанный факт
  ✓ в карточку не добавилось ни одного факта
```

подсунут пример с цифрой («Гарантия 3 года») — код обязан его выбросить.
Выбрасывает.

```

примеры ответа: ["Договор и смета до начала работ"]
```

## Что нужно от владельца

Одна миграция — колонка под подсказки. Код уже подстрахован: пока колонки
нет, подсказки просто не сохраняются и интервью идёт на каноничных вопросах,
ничего не падает. SQL передан владельцу текстом.

## Дальше по 2.4

Разбор ходов прогона с `trace_id` — нужен `DEBUG_TOKEN`: прод отдаёт трейсы
только с ним (проверено, без токена `403`). Читалка готова:
`npm run razbor -- --minutes 90` печатает по каждому ходу trace_id, вопрос,
ответ, ветку, вердикт, флаги словами, латентность и стоимость.
