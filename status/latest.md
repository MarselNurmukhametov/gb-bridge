## Сделано

**1. Мозг интервью — закрыт.** Ход владельца больше не пишется в факты
подряд. Модель классифицирует ход по P2 пп.1–3 (`readTurn`): `fact` ·
`objection` · `question` · `later` · `garbage`. Факты извлекаются **только**
из `fact`; на остальных ветках карточка не трогается, вопрос остаётся
прежним, агент отвечает по смыслу и повторяет вопрос. В телеметрию идёт
флаг `TURN_OBJECTION` / `TURN_GARBAGE` / `TURN_QUESTION` / `TURN_LATER`.

Артефакт — в `e2e/latest.txt`, раздел «ТРУДНЫЙ СОБЕСЕДНИК»: четыре хода,
ноль мусорных фактов, вопрос не сдвинулся ни разу.

**2. Живой режим — скрипт готов, из этой среды не запускается.**
`npm run e2e:live` поднимает тот же путь на настоящей модели (и на
настоящей базе, если есть ключи). Прогон из моей среды невозможен: прокси
закрывает провайдеров. Дословно из вывода:

```
Живой прогон не запущен: https://api.openai.com/v1 ответил 403.
```

Скрипт сначала пингует провайдера и печатает причину, а не молчаливое
«фактов не нашлось». Запустится там, где есть сеть (машина владельца, CI
с секретами) — тогда `e2e/live.txt` появится в мосту.
