# Статус · 01.08, ночь · SITE-READER v3 — доказательный конвейер · приёмка 5/5 с эталоном ChatGPT

## Что сделано (шаг 1 порядка работ — целиком, плюс injection из шага 3)

**Конвейер переписан с «заполни поля» на доказательные утверждения:**

- **Этап 0** — целевая сущность первым вызовом: display_name, юрлицо,
  entity_type, primary_topics, страна, язык. К ней привязывается каждый факт.
- **Этап 1** — страницы по ролям (about/services/contacts/pricing/…),
  по 1–5 лучших на роль, а не «первые 15 подряд»; блог и вакансии — ноль.
- **Проход A** — модель возвращает атомарные утверждения:
  predicate + object + `relation_to_target` + `claim_type` + evidence
  {url, дословная цитата} + confidence. Карточку она не заполняет.
- **Проход B** — верификация отдельным вызовом: судья видит только
  утверждение и цитату, сырой сайт — нет. Четыре вопроса по спеке.
  Контакты и география — исключение: их сверяет код с цитатой
  (судья рубил «Телефон: +7…» из-за разницы форматов записи).
- **Проход C (код)** — сборка карточки из проверенного: не-direct вон,
  маркетинговые счётчики не в доверие, template_content вон, цитаты-описания
  чужих продуктов («PandaOMICs is an AI-powered platform…») — third-party
  даже если модель сказала direct; дальше инспекции v2 (пустышки, дубли,
  лимиты, перевод — бренды и имя дела не переводятся).
- **Статусы полей**: `not_found` со списком просмотренных ролей —
  «не найдено в проверенных источниках», не «цен нет». Заполненные —
  `company_asserted` / `pending_owner_confirmation` (<0.8 — на подтверждение).
- **Prompt injection**: контент сайта — данные, не инструкции; команда в
  тексте страницы не исполняется, ход помечается `INJECTION_IN_CONTENT`,
  остальной сайт читается.

## Что вскрыла приёмка и как починено (всё тестами)

- проход B рубил контакты из-за форматов номера → точные данные сверяет код;
- платформы с /platforms становились услугами → цитата-описание чужого
  продукта детектится кодом, промпту добавлен явный пример;
- имя дела переводилось («Метахим») → бренд из перевода исключён;
- «анализ данных» ложно триггерил мед-проверку → сужена до клинического
  набора;
- сверка смысла услуг по буквам ломалась о русскую морфологию → сопоставляет
  модель, построчный вывод в отчёте.
