# Статус: витрина паспорта

**Что сделано.** Страница `/t/<slug>` перестала быть чатом. Слева паспорт,
справа агент — как в эталоне реестра, состояние 3.

На витрине:

- шапка: название, описание дела одной строкой, полный адрес паспорта с кнопкой «копировать»;
- крупные факты — цена и срок из слота 2 (число отделяется от остатка фразы);
- абзац-ответ целиком, с меткой «его цитируют ИИ»;
- полная раскладка по слотам, у каждого факта источник: домен, с которого он взят, или «со слов владельца»;
- пустой слот — пробелом, с объяснением, что теряется;
- тёмный блок машинного слоя: адрес JSON, типы разметки, которые реально уходят в head, открытые двери краулерам.

Витрина, JSON-LD и `/api/lavka/<slug>.json` собираются из одних фактов —
второго ввода данных нет.

**Границы честности на витрине.** Метки говорят, откуда взяты факты, и не
обещают проверок, которых мы не делаем. Счётчиков обращений нет — считать
их пока нечем, а рисовать выдуманные числа в блоке «то же самое для ИИ»
нельзя. Сторожем идёт тест: ни одна строка витрины не проходит границу.
