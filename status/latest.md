# Статус: каждой роли своя модель, выбор — по замеру

## План ролей

| роль | модель | чем обоснован выбор |
|---|---|---|
| чтение сайта | сильная (sol) | 20 фактов против 12 у дешёвой на том же тексте |
| упаковка паспорта | дешёвая (luna) | пересказ готовых фактов, сторожа проверяют кодом |
| диалог с клиентом | дешёвая (luna) | ноль нарушений у всех трёх моделей, в 18 раз дешевле |

Порядок старшинства: переменная окружения → план → модель провайдера.
План и причина видны в `/api/health`.

## Замер диалога: три модели, один разговор

| модель | цена шести реплик | нарушений правил |
|---|---|---|
| luna | 0,83 ₽ | 0 |
| terra | 5,30 ₽ | 0 |
| sol | 15,27 ₽ | 0 |

Дешёвая единственная предложила альтернативу на «нужны резиновые сапоги»;
средняя под конец отправила клиента звонить. Работу на этой роли делает
промпт, а не тариф.

## Агент

- паспорт отдаётся целиком, а не выжимкой по словам вопроса: экономия на
  контексте стоила две копейки, а агент не видел половины фактов;
- контакт не просится в каждой реплике;
- цена хода вернулась в ответ API — раньше жила только в трейсе.

## Нужно действие владельца

На превью выставлены переменные MODEL_EXTRACT / MODEL_COMPILE /
MODEL_DIALOG = luna. Они старше плана — и чтение идёт на дешёвой, паспорт
выходит на 4 факта вместо 20. Чтобы план заработал, эти три переменные
надо убрать (или выставить MODEL_EXTRACT=gpt-5.6-sol).

**Тесты.** 493 зелёных.
