## Где рвётся живой прогон (правило автономии: не молчать)

Скрипт `npm run e2e:live` написан и работает: пингует провайдера, при отказе
печатает причину, при успехе гоняет тот же путь на настоящей модели.
Запустить его из среды разработки нельзя — прокси закрывает провайдеров.
Что пробовал, дословно по кодам ответа:

```

https://api.openai.com/v1/models       000  (403 на туннеле)
https://gb-agent-git-main-gb16.vercel.app/api/health   000
https://api.anthropic.com/v1/models    401  ← сеть есть, нужен ключ
```

Единственный доступный провайдер — Anthropic. Под него добавлен адаптер
(`src/lib/llm/anthropic.ts`, свой протокол `/v1/messages`), провайдер
выбирается конфигом, бизнес-логика не изменилась. Ключа `ANTHROPIC_API_KEY`
в окружении нет.

**Нужно одно из двух** (любое разблокирует `e2e/live.txt` сегодня же):
1. `ANTHROPIC_API_KEY` в окружении разработки, либо
2. разрешить `api.deepseek.com` в allowlist окружения — тогда живой прогон
   пойдёт на штатном провайдере из ТЗ.

Хаком обходить не стал: подделывать латентности в мок-режиме — это ровно то,
что чек-лист запрещает («латентности > 200 мс, не мок»).
